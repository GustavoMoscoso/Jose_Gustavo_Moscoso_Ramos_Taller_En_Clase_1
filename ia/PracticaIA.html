Documentación del Uso de Inteligencia Artificial

1. ¿Qué se pidió a la IA? (Prompt utilizado)

Se solicitó a la herramienta de Inteligencia Artificial: Crea una página web en HTML5 puro (sin CSS ni JavaScript) para el club universitario de deportes electrónicos GGspol de la ESPOL, que incluya una sección de bienvenida, lista de juegos competitivos, tabla de próximos torneos, requisitos de inscripción y datos de contacto.

2. ¿Qué resultado entregó la IA?

La IA generó una estructura base funcional con etiquetas semánticas (<header>, <main>, <section> y <footer>), una tabla básica con tres torneos de ejemplo y una lista no ordenada de videojuegos. Sin embargo, incluía estilos CSS internos dentro de una etiqueta <style> y carecía de los metadatos personalizados y las rutas relativas de nuestro proyecto.

3. ¿Qué modificaciones se realizaron?

  • Se eliminó por completo el bloque <style> para cumplir la restricción de usar únicamente HTML puro.
  • Se adaptó el bloque <head> incorporando mis metadatos de autor y el ícono local Gengar.ico.
  • Se integró la barra de navegación horizontal (<nav>) con rutas relativas hacia ../../index.html y las demás prácticas.
  • Se agregaron separadores <hr> entre cada sección y se personalizó el pie de página reglamentario.

4. ¿Qué aprendió del proceso?

Aprendí que la Inteligencia Artificial acelera la creación de contenido base y estructuras repetitivas (como tablas), pero requiere supervisión técnica humana para depurar código no permitido (como estilos incrustados), corregir niveles de carpetas en rutas relativas (../ y ../../) y garantizar una semántica HTML limpia.
