03 / Diseño e interfaces

Una ruta clara,
en horizontal.

Una barra superior conecta las páginas principales y las secciones de este ejercicio. En móvil, sus enlaces se agrupan detrás de un control desplegable.

Comparar con el menú vertical

El concepto

La navegación horizontal aprovecha el ancho disponible y mantiene las opciones principales en una sola zona. Es apropiada para un conjunto breve de destinos, como Inicio, otra práctica y los apartados de esta página.

La identidad visual conserva los fondos Deep Navy, bordes pizarra y acentos de hielo del portafolio.

La estructura

El elemento nav describe la navegación. Una lista organiza los enlaces y un botón identifica el panel que controla mediante aria-controls.

Las clases navbar-expand-md y collapse navbar-collapse de Bootstrap muestran el menú completo desde 768 px y lo hacen desplegable por debajo de ese ancho. El bundle local actualiza aria-expanded al abrir y cerrar.

Pruébalo en el navegador

  1. Reduce la ventana a menos de 768 px y abre el menú con su botón.
  2. Usa Tab y Enter para recorrer y activar los enlaces.
  3. Selecciona Concepto o Estructura para desplazarte a una sección real.
  4. Abre la práctica vertical para comparar una barra superior con una columna lateral.
