Preguntas sobre JavaScript

  1. ¿Qué diferencia hay entre let y const en este ejercicio?

    • let se usa para variables cuyo valor puede cambiar durante la ejecución, por ejemplo: subtotal, total, precioUnitario o cantidadProducto.
    • const se usa para valores o referencias que no serán reasignados, por ejemplo los elementos obtenidos con getElementById o la constante PORCENTAJE_DESCUENTO.

  2. ¿Por qué precio.value debe convertirse con Number()?

    Porque precio.value obtiene el dato como texto, aunque el elemento input sea de tipo number. Para poder hacer operaciones matemáticas correctamente, el valor se convierte a número usando Number().

  3. ¿Qué tipo de dato devuelve descuento.checked?

    descuento.checked devuelve un dato booleano:

    • true, si el checkbox está marcado.
    • false, si el checkbox no está marcado.

  4. ¿Qué función se encarga de calcular el subtotal?

    function calcularSubtotal(precioUnitario, cantidadProducto) {
    return precioUnitario * cantidadProducto;
}

    La función recibe el precio unitario y la cantidad del producto. Después, multiplica ambos valores y retorna el subtotal.

  5. ¿Qué función retorna un objeto?

    function crearObjetoVenta(
    nombreProducto,
    nombreCategoria,
    subtotal,
    valorDescuento,
    total
) {
    let venta = {
        producto: nombreProducto,
        categoria: nombreCategoria,
        subtotal: subtotal,
        descuento: valorDescuento,
        total: total
    };

    return venta;
}

    La función crearObjetoVenta() crea un objeto llamado venta y lo devuelve mediante la instrucción return.

  6. ¿Qué evento permite actualizar el nombre del producto mientras se escribe?

    • El evento input.
    • Este evento se ejecuta cada vez que el usuario escribe, borra o modifica el contenido del campo.

  7. ¿Qué método se usa para seleccionar elementos por id?

    document.getElementById("id_del_elemento");

    El método getElementById() permite obtener un elemento HTML mediante el valor de su atributo id.

  8. ¿Por qué se usa textContent para mostrar resultados?

    • Porque textContent permite cambiar el texto visible de un elemento HTML desde JavaScript.
    • Se utiliza para mostrar resultados como el producto, la categoría, el subtotal, el descuento y el total sin recargar la página.

  9. ¿Qué ocurre si el precio ingresado es 0?

    La función validarDatos() detecta que el precio no es válido, porque debe ser mayor que 0.
