# GGspol Hub - Prototipo Frontend (Lección #2)

## Descripción
Este proyecto corresponde a la primera fase del sistema de gestión para el club de deportes electrónicos GGspol. 
El alcance de esta entrega abarca únicamente el desarrollo del frontend funcional y navegable desde el lado del cliente, simulando el comportamiento del sistema sin conexión a un backend.

## Herramientas Utilizadas
- **HTML5:** Para la estructura semántica de las pantallas.
- **CSS3:** Para el diseño visual y la disposición ordenada del contenido.
- **JavaScript:** Para la inserción de datos simulados mediante objetos locales y las validaciones básicas de los formularios.

## Funcionalidades del Prototipo
- **Dashboard (`index.html`):** Muestra tarjetas con métricas simuladas (Jugadores activos, Torneos en curso) y una tabla que se llena dinámicamente mediante JavaScript.
- **Creación de Torneos (`torneos.html`):** Contiene un formulario con validaciones básicas del lado del cliente. Al enviarlo, previene la recarga de la página y muestra mensajes de éxito o error.

## Instrucciones de Ejecución
Para visualizar el proyecto, simplemente abra el archivo `index.html` en cualquier navegador web moderno.
