Descripción de la Práctica

Demostración funcional de las etiquetas de listas en HTML (<ul>, <ol>, <li>, <dl>, <dt> y <dd>) junto con sus atributos de personalización.

1. Lista no ordenada (<ul> y <li>)

Agrupa elementos donde el orden secuencial no altera el significado (usa viñetas por defecto):

  • HTML5 (Estructura)
  • CSS3 (Presentación visual)
  • JavaScript (Interactividad)
  • Git y GitHub (Control de versiones)

2. Lista ordenada (<ol> y <li>)

Enumera elementos que siguen una secuencia o prioridad obligatoria:

  1. Analizar los requerimientos del sitio web.
  2. Crear la estructura de carpetas del proyecto.
  3. Maquetar los documentos con etiquetas HTML semánticas.
  4. Validar que todos los hipervínculos y rutas relativas funcionen.

3. Lista ordenada con inicio personalizado (Atributo start y value)

El atributo start="10" indica que la lista empiece en 10, y value="25" salta la numeración en un ítem específico:

  1. Práctica 10: CSS
  2. Práctica 11: CopyPaste
  3. Práctica 12: Hipervínculos
  4. Ítem con salto personalizado al número 25 usando el atributo value
  5. Ítem consecutivo (número 26)

4. Lista ordenada con letras (Atributo type="A" y type="a")

Letras mayúsculas (type="A"):

  1. Cabecera del documento (<header>)
  2. Cuerpo principal (<main>)
  3. Pie de página (<footer>)

Letras minúsculas (type="a"):

  1. Nombre del estudiante
  2. Correo electrónico institucional
  3. Referencia de copyright académico

5. Lista con números romanos (Atributo type="I" y type="i")

Números romanos en mayúsculas (type="I"):

  1. Unidad I: Estructura y estilo de un documento web
  2. Unidad II: Diseño web adaptable (Responsive)
  3. Unidad III: Programación del lado del cliente

Números romanos en minúsculas (type="i"):

  1. Subtema i: Estructura global
  2. Subtema ii: Semántica HTML5
  3. Subtema iii: Video y Audio

6. Lista con viñetas personalizadas en HTML (Atributo type en <ul>)

Viñeta cuadrada (type="square"):

  • Computadora de escritorio (PC)
  • Servidor en la nube
  • Sistema de alimentación ininterrumpida (UPS)

Viñeta circular vacía (type="circle"):

  • Laptop portátil
  • Smartphone táctil
  • Router / Dispositivo de red

Viñeta de disco relleno (type="disc"):

  • Computador All in One
  • Celular con teclado físico

7. Lista anidada (Combinación de listas dentro de listas)

Permite representar jerarquías como la estructura de carpetas de nuestro taller:

  • Directorio Raíz (Moscoso_Ramos_Tll_1)
    • audio/
    • css/
    • img/
      1. Cloud-2.png
      2. icon/Gengar.ico
    • Pages/
      1. Copy_Paste/
      2. IA/
      3. Nube/ (8 dispositivos mapeados)
    • video/
  • index.html

8. Lista ordenada descendente (Atributo booleano reversed)

Invierte el orden de la numeración de mayor a menor (ideal para conteos regresivos o rankings):

  1. Fase 5: Despliegue y entrega del archivo .rar
  2. Fase 4: Pruebas de navegación e hipervínculos
  3. Fase 3: Inserción de recursos multimedia
  4. Fase 2: Codificación de páginas en HTML
  5. Fase 1: Planificación de la estructura del directorio

9. Lista de definición (<dl>, <dt> y <dd>)

Se utiliza para glosarios de términos técnicos, donde <dt> es el término y <dd> su definición:

HTML (HyperText Markup Language)
Lenguaje de marcado estándar utilizado para estructurar y desplegar páginas web y sus contenidos.
Ruta Relativa
Dirección que indica la ubicación de un archivo tomando como punto de partida la carpeta del documento actual.
Etiqueta Semántica
Elemento de HTML5 que describe claramente su significado tanto para el navegador como para el desarrollador (por ejemplo: <header>, <nav>, <main>, <footer>).
