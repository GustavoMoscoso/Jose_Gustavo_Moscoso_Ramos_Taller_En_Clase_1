Descripción de la Práctica

Demostración del uso de etiquetas multimedia para imágenes en HTML (<img>, <figure>, <figcaption>, <picture>, <source>, <map> y <area>), integrando la práctica de mapeo de dispositivos en la nube desarrollada en clase.

1. Imagen desde un directorio local (Atributos src, alt, title, width y height)

Explicación: Carga una imagen alojada en la carpeta ../img/ del proyecto utilizando una ruta relativa. Pasa el cursor sobre la imagen para ver el atributo title.

2. Imagen desde una dirección web (URL Externa)

Explicación: Inserta una imagen alojada en un servidor externo mediante una ruta absoluta HTTP/HTTPS.

3. Imagen como hipervínculo (<a> envolviendo a <img>)

Explicación: Al colocar una etiqueta <img> dentro de <a>, la imagen se vuelve clicable. Haz clic en la imagen para ir al portal de la ESPOL en una nueva pestaña:

4. Imagen semántica con pie de foto (<figure> y <figcaption>)

Explicación: La etiqueta <figure> agrupa una ilustración o diagrama, mientras que <figcaption> le asigna una leyenda descriptiva oficial.

5. Imágenes adaptables con <picture> y <source>

Explicación: El elemento <picture> permite definir múltiples fuentes (<source>) para que el navegador cargue una imagen distinta según el ancho de la pantalla (redimensiona la ventana del navegador para probarlo).

6. Mapa de Imagen Interactivo (<map>, <area>, usemap, shape y coords)
