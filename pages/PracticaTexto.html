Descripción de la Práctica

Esta página demuestra el funcionamiento semántico y visual de todas las etiquetas HTML destinadas a la estructuración de encabezados, párrafos, resaltado de texto, citas bibliográficas y fragmentos de código.

1. Etiquetas de Encabezado (<h1> a <h6>)

Definen seis niveles de jerarquía para títulos y subtítulos dentro de un documento web:

Ejemplo de Encabezado <h1> (Nivel 1 - Principal)

Ejemplo de Encabezado <h2> (Nivel 2 - Sección)

Ejemplo de Encabezado <h3> (Nivel 3 - Subsección)

Ejemplo de Encabezado <h4> (Nivel 4 - Apartado)

Ejemplo de Encabezado <h5> (Nivel 5 - Subapartado)
Ejemplo de Encabezado <h6> (Nivel 6 - Mínimo nivel)

2. Etiqueta <p> (Párrafo)

Explicación: Agrupa oraciones dentro de un bloque de texto estructurado con márgenes automáticos superiores e inferiores.

Demostración: Este es un primer párrafo de ejemplo creado con la etiqueta <p> para la materia de Desarrollo de Aplicaciones Web y Móviles en la ESPOL.

Demostración: Este es un segundo párrafo independiente que se muestra automáticamente debajo del anterior.

3. Etiqueta <br> (Salto de línea)

Explicación: Es una etiqueta vacía que inserta un salto de línea simple dentro de un mismo bloque de texto (útil en direcciones o poemas).

Escuela Superior Politécnica del Litoral (ESPOL)
Campus Gustavo Galindo Velasco, Km. 30.5 Vía Perimetral
Facultad de Ingeniería en Electricidad y Computación (FIEC)
Guayaquil, Ecuador

4. Etiqueta <hr> (Cambio temático / Línea horizontal)

Explicación: Representa una transición temática entre párrafos o secciones y se dibuja como una línea horizontal divisoria.

Texto superior antes del divisor temático interno:

Texto inferior después del divisor temático interno.

5. Etiqueta <b> (Negrita de atención visual)

Explicación: Aplica texto en negrita para atraer la atención hacia palabras clave o nombres de productos sin otorgarles mayor importancia semántica.

Demostración: En el desarrollo frontend utilizamos editores como Visual Studio Code y navegadores como Google Chrome.

6. Etiqueta <strong> (Importancia semántica fuerte)

Explicación: Indica que su contenido tiene una gran importancia, seriedad o urgencia semántica (se visualiza en negrita).

Demostración: Restricción obligatoria: Todo el desarrollo de este taller debe realizarse únicamente con HTML puro.

7. Etiqueta <i> (Cursiva para términos técnicos o extranjeros)

Explicación: Muestra el texto en cursiva para denotar extranjerismos, taxonomías, pensamientos o términos técnicos.

Demostración: El diseño adaptable se conoce en inglés bajo el concepto de Responsive Web Design o metodología Mobile First.

8. Etiqueta <em> (Énfasis semántico)

Explicación: Aplica énfasis en la pronunciación o el sentido de una palabra dentro de una oración.

Demostración: Debes entregar todas las páginas correctamente vinculadas desde el archivo principal.

9. Etiqueta <u> (Texto subrayado / Anotación no textual)

Explicación: Representa texto con una anotación no articulada, como nombres propios específicos o palabras con errores ortográficos intencionales.

Demostración: Es importante escribir correctamente la palabra hipervínculo y evitar enlaces rotos.

10. Etiqueta <mark> (Texto resaltado)

Explicación: Resalta un fragmento de texto (como un marcador amarillo) por su relevancia en el contexto actual.

Demostración: Para aprobar la revisión, verifica que no existan archivos multimedia faltantes en las carpetas del proyecto.

11. Etiqueta <small> (Texto secundario o legal)

Explicación: Reduce el tamaño de fuente un nivel para representar comentarios secundarios, cláusulas o derechos de autor.

Demostración: Suscripción gratuita al boletín estudiantil. *Aplican términos y condiciones de uso académico en ESPOL 2026.

12. Etiqueta <sup> (Superíndice)

Explicación: Muestra el texto elevado y con menor tamaño, ideal para exponentes matemáticos, fechas ordinales o referencias al pie.

Demostración: El Teorema de Pitágoras establece que a2 + b2 = c2, y la famosa ecuación de Einstein es E = m·c2.

13. Etiqueta <sub> (Subíndice)

Explicación: Muestra el texto por debajo de la línea base, utilizado en fórmulas químicas o bases numéricas.

Demostración: La fórmula química del agua es H2O, la del dióxido de carbono es CO2 y el número binario 10102 equivale a 1010.

14. Etiqueta <del> (Texto eliminado)

Explicación: Representa texto que ha sido borrado o reemplazado respecto a una versión previa del documento (se muestra tachado).

Demostración: La entrega del taller estaba programada para el lunes 26 de octubre.

15. Etiqueta <ins> (Texto insertado)

Explicación: Marca texto que ha sido añadido recientemente al documento (se muestra subrayado y suele combinarse con <del>).

Demostración: Fecha de entrega actualizada: 26 de octubre viernes 30 de octubre de 2026.

16. Etiqueta <abbr> (Abreviatura o acrónimo)

Explicación: Define una abreviatura o sigla; al pasar el cursor por encima muestra su significado completo gracias al atributo title.

Demostración (pasa el mouse sobre las siglas): Estudiamos HTML y CSS en la ESPOL.

17. Etiqueta <cite> (Referencia al título de una obra)

Explicación: Se utiliza para marcar el título de un libro, artículo académico, película, pintura o estándar técnico.

Demostración: El estándar oficial de la web moderna está documentado en HTML Living Standard de WHATWG y en MDN Web Docs.

18. Etiqueta <blockquote> (Cita extensa en bloque)

Explicación: Define una cita textual extensa tomada de otra fuente, aplicando sangría automática en el navegador.

"El poder de la Web está en su universalidad. El acceso por cualquier persona, independientemente de la discapacidad, es un aspecto esencial." — Tim Berners-Lee, creador de la World Wide Web.

19. Etiqueta <q> (Cita corta en línea)

Explicación: Inserta una cita breve dentro de un párrafo agregando comillas tipográficas de forma automática.

Demostración: Como indica la guía del taller: El objetivo principal es demostrar dominio de la estructura HTML y organización de archivos.

20. Etiqueta <address> (Información de contacto)

Explicación: Proporciona datos de contacto del autor del documento o de una sección (correo, teléfono, ubicación).

21. Etiqueta <pre> (Texto preformateado)

Explicación: Conserva exactamente los espacios en blanco, tabulaciones y saltos de línea tal como fueron escritos en el archivo HTML.

ApellidoUno_ApellidoDos_Tll_1/

├── js/
├── Pages/
│   ├── Copy_Paste/
│   └── IA/
├── video/
└── index.html

22. Etiqueta <code> (Código de computadora)

Explicación: Muestra texto con fuente monoespaciada para representar fragmentos de código fuente.

Demostración: Para enlazar un ícono en la pestaña del navegador usamos <link rel="icon" href="../img/icon/Gengar.ico">.

23. Etiqueta <kbd> (Entrada de teclado)

Explicación: Representa las teclas o comandos que el usuario debe presionar en su teclado.

Demostración: Para guardar tus cambios en el editor presiona Ctrl + S, y para inspeccionar la página web en el navegador presiona F12.

24. Etiqueta <samp> (Salida de muestra de un sistema)

Explicación: Representa el mensaje o resultado que devuelve un programa informático o consola.

Demostración: Al validar el documento HTML sin errores, la terminal mostró el mensaje: Document checking completed. No errors or warnings to show.

25. Etiqueta <var> (Variable matemática o de programación)

Explicación:Identifica el nombre de una variable dentro de una expresión matemática o algoritmo.

Demostración: El área de un triángulo se calcula multiplicando la base b por la altura h dividida para 2: Área = (b × h) / 2.

26. Etiqueta <span> (Contenedor genérico en línea)

Explicación: Es un contenedor en línea neutro que permite agrupar palabras o frases dentro de un texto sin generar saltos de línea.

Demostración: El código de esta asignatura es SOFG1006 perteneciente a la carrera de Ingeniería.

27. Etiqueta <div> (Contenedor genérico de bloque)

Explicación: Es un contenedor de nivel de bloque que permite agrupar varios elementos HTML para estructurar divisiones lógicas.

Bloque agrupado dentro de un <div>

Este párrafo y su subtítulo están contenidos dentro de una misma división genérica <div>.
